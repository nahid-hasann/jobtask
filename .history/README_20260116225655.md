# 🛒 JobTask Store — Next.js E‑commerce Application

A modern, responsive **e‑commerce web application** built with **Next.js 15 (App Router)**. This project demonstrates core web development concepts including **SSR**, **API integration**, **Firebase Authentication**, and **dynamic routing**.

## ✨ Features Implemented

### 1️⃣ Dynamic Landing Page

A fully responsive landing page with **7 distinct sections**:

* 🎯 Hero section with modern gradient UI
* 🏢 Brand / Trusted by section
* ⭐ Features / Why Choose Us grid
* 🛍️ Trending categories with hover effects
* ℹ️ About Us section
* 📩 Newsletter subscription card
* ❓ FAQ accordion section

---

### 2️⃣ Authentication System

* 🔐 **Sign Up:** Create account using email & password
* 🔓 **Login:** Secure login via Firebase Authentication
* 🚪 **Logout:** Functional logout button
* 🧭 **Dynamic Navbar:**

  * Guests → `Login`
  * Authenticated users → `Logout` + User Email

---

### 3️⃣ Products / Items System

* 📦 **Product List:** Fetches items from internal API
* 🔍 **Product Details:** Dynamic route for each product
* ⚠️ **Error Handling:** Custom "Item Not Found" UI

---

### 4️⃣ API Integration

* Uses built‑in **Next.js API Routes** (`/api/items`)
* No external Express server required
* Easy deployment on Vercel

## 📂 Route Summary

| Route         | Description               | Access |
| ------------- | ------------------------- | ------ |
| `/`           | Landing page (7 sections) | Public |
| `/items`      | All products list         | Public |
| `/items/[id]` | Product details           | Public |
| `/login`      | Login page                | Guest  |
| `/register`   | Registration page         | Guest  |

## ⚙️ Setup & Installation

Follow the steps below to run the project locally:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/nahid-hasann/jobtask.git
cd jobtask
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Configure Environment Variables

Create a `.env.local` file in the root directory and add your Firebase configuration:

```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

### 4️⃣ Run the Development Server

```bash
npm run dev
```

### 5️⃣ Open in Browser

Visit 👉 **[http://localhost:3000](http://localhost:3000)**
